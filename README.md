# CREDO Digital Studio

Static website (HTML + CSS + JS). No build step.

Folder layout (everything must stay together at the repo root):

```
index.html
style.css
script.js
vercel.json
favicon.ico / favicon.svg / favicon-16x16.png / favicon-32x32.png / apple-touch-icon.png
images/   <- all .jpg photos
brand/    <- logo .svg files
```

## Deploy on Vercel
Import the repo → Framework Preset: **Other** → leave Build Command and Output Directory empty → Deploy.
